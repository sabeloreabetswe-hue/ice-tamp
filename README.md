# ICE-TAMP-
Truck Asset Matchmacking System
 Logistics Dashboard Web App

A modern React + Vite application for managing logistics workflows across freight owners, transporters, and administrators. This project combines role-based pages, dashboards, load and truck management, ratings, dispute handling, and shipment tracking in a single modular UI.

## Key Features

- Role-based UI for freight owners, transporters, and admin users
- Load creation, editing, and shipment tracking
- Truck registration and management
- Match requests and load recommendations
- Ratings and review flows for carriers and shippers
- Dispute and verification management
- Dashboard widgets, activity history, and sidebar navigation

## Tech Stack

- React 
- Vite 
- Tailwind CSS 
- React Router DOM 
- ESLint for linting
- PostCSS + Autoprefixer for styling support
